# 🏡 AI 家庭生活小幫手

專為台灣家庭（長輩、家庭主婦、上班族、學生）設計的單機生活助理網頁 App。
不需登入、不需伺服器，所有資料都存在瀏覽器的 LocalStorage，關掉再打開資料仍會保留。

## 功能

- 📅 **待辦事項**：大字日期＋可愛時鐘＋一鍵語音播報今天日期時間、國曆/農曆月曆（初一、十五自動標紅字）、雙擊日期新增待辦、勾選完成會自動變淡色、左滑顯示「刪除」再點一下才真的刪除、農曆初一十五前兩天自動加入提醒
- 🧮 **計算機**：大按鍵、粉紅／粉藍配色切換、下方顯示最近 10 筆計算紀錄，並可把任一筆結果加進「本次購物小計」
- 🙏 **重要節日**：點節日卡片查看除夕、元宵、端午、中元、中秋、重陽、冬至的拜拜對象與供品，內容可直接點擊編輯、新增或刪除項目
- 🎋 **求籤**：六十甲子籤趣味小遊戲（星空籤卡風格），點卡牌抽一支籤看今日運勢，搖籤、開籤都有音效，結果會留著給下一位家人玩
- ☁️ **天氣**：自動抓取使用者目前位置的**即時天氣**（透過 [Open-Meteo](https://open-meteo.com) 免費 API，不需申請金鑰），顯示溫度、紫外線、風力、濕度、穿衣建議與一週預報；沒有網路或定位時會改顯示示意資料
- 💡 所有頁面的「使用小提示」都改成可收合的小按鈕，點一下才展開，避免字體調大時把重要內容擠到畫面下方
- 🗺 **地圖**：輸入目的地一鍵開啟 Google 地圖導航（Android／iPhone 皆可），內建可自訂的「最常用查詢」捷徑（農民曆、附近醫院／藥局／超市／廟宇／郵局），可新增、刪除，並支援上傳照片當圖示（會自動壓縮）
- 📰 **新聞**：自動抓取「公視新聞網」即時新聞（透過免費的 rss2json 服務，不需申請金鑰），可另開分頁閱讀全文；沒有網路時會改顯示示意內容；下方另有可自訂的「常用連結」快速前往常用網站，同樣支援上傳照片當圖示
- 🎙 **AI 語音筆記**：按住說話，放開自動整理成待辦事項清單
- ⚙️ **設定**：字體大小、主題色、深色／淺色模式、語音播報速度與男女聲
- 💾 資料可匯出/匯入 JSON 備份

## 如何上傳到 GitHub 並上線（GitHub Pages）

1. 在 GitHub 建立一個新的 repository（例如 `family-assistant`）。
2. 把這個資料夾內的**全部檔案**都上傳到 repository 根目錄，缺一不可：
   - `index.html`
   - `style.css`
   - `app.js`
   - `custom-icon.png`（手機加入主畫面用的圖示，可以換成你自己喜歡的照片，檔名要維持 `custom-icon.png`，正方形圖片效果最好）
   - `README.md`（非必要，只是說明文件，不上傳也不影響網站運作）

   ⚠️ 不要上傳 `family-assistant.zip` 壓縮檔本身，GitHub Pages 需要看到解壓縮後的檔案。
3. 到 repository 的 **Settings → Pages**，Source 選擇 `main` 分支、資料夾選 `/(root)`，儲存。
4. 幾分鐘後，GitHub 會給你一個網址，例如：
   `https://你的帳號.github.io/family-assistant/`

## 手機加入主畫面（像 App 一樣使用）

**iPhone (Safari)：**
1. 用 Safari 打開上面的網址。
2. 點下方分享按鈕（□ 加上箭頭）。
3. 選「加入主畫面」。
4. 桌面就會出現「生活小幫手」的圖示，點下去會全螢幕打開，不會看到網址列，跟真的 App 一樣。

**Android (Chrome)：**
1. 用 Chrome 打開網址，右上角選單點「加到主畫面」或「安裝應用程式」。

我已經先做了一個可愛的莫蘭迪粉色系小房子圖示 `custom-icon.png` 給你當預設圖示，如果你有想放的照片，直接把你的圖片改名成 `custom-icon.png`（建議正方形、至少 512×512）覆蓋上傳即可。

## 本機測試

不需要安裝任何套件，直接用瀏覽器打開 `index.html` 即可（或用 VS Code 的 Live Server 擴充功能）。

## 備註

- 農曆換算使用 1900–2100 年通用農曆演算法，準確度足以日常使用。
- 語音辨識（語音筆記）需要瀏覽器支援 Web Speech API 並允許麥克風權限；單次錄音最長 60 秒。**iPhone 的 Safari 瀏覽器目前不支援這個功能**（蘋果的限制，無法用網頁解決），建議在 Android 手機或電腦的 Chrome 瀏覽器上使用。錄音內容只會存進「筆記記錄」，不會自動加入待辦事項，要加入待辦需自己按每筆記錄旁的「➕待辦」。
- 新聞 RSS 兩次更換來源（公視新聞網、自由時報）在使用者實機測試下仍抓不到資料，因此改為穩定可靠的「常用網站」捷徑，避免功能長期無法使用。
- 天氣使用 Open-Meteo 免費 API 抓取即時資料（需允許定位權限＋網路連線），不需要申請金鑰；若離線則顯示示意資料。
- 新聞使用公視新聞網 RSS，透過免費的 rss2json 服務轉成 JSON（不需要申請金鑰）；若離線則顯示示意內容。已加入可自訂的「常用連結」區塊供快速前往常用網站。
